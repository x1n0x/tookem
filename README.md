# Электромир — сайт производителя электрооборудования

Лендинг компании **Электромир** ([tookem.kz](https://tookem.kz)) — производство электрощитов в Алматы: ВРУ, ЩЭ, КТПН, АВР. 20+ лет опыта, работа по Казахстану и СНГ.

## О проекте

Статический одностраничный сайт без бэкенда и сборщиков — чистые HTML, CSS и JavaScript. Развёрнут на хостинге с Plesk (nginx + Apache), деплой — через Git из этого репозитория.

Особенности:

- Адаптивная вёрстка и фирменные шрифты (Nexa, Uni Sans).
- Интерактивная карта на [2GIS Maps API](https://api.2gis.ru) с кнопками связи (WhatsApp).
- SEO-разметка: Open Graph, Schema.org / JSON-LD (Product, Organization), `sitemap.xml`, `robots.txt`.
- Чистые URL, редиректы, страница 404 и заголовки безопасности настроены в [`.htaccess`](.htaccess).
- `style.css` и `script.js` кэшируются браузером надолго, поэтому подключены с версией `?v=ГГГГММДД` — после правки стилей или скрипта обновите её во всех HTML-файлах.

## Структура

```
index.html        — главная страница
404.html          — страница ошибки
style.css         — стили
script.js         — логика (карта, анимации, интерактив)
.htaccess         — чистые URL, редиректы, 404 и заголовки безопасности
sitemap.xml       — карта сайта для поисковиков
robots.txt        — правила индексации
assets/           — изображения, логотипы, шрифты, фавиконы
```

## Локальный запуск

Сборка не требуется. Достаточно поднять любой статический сервер из корня репозитория:

```bash
npx serve .
# или
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Деплой

Push в ветку `main` → в Plesk (Сайты и домены → Git) подтянуть обновления, если автодеплой по webhook не настроен.
